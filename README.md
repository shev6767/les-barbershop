# Барбершоп «Лес»

Сайт для задания 4 по дисциплине «Разработка и реализация проектов».

Страницы:

- index.html - главная
- services.html - услуги и цены
- works.html - примеры работ
- contacts.html - адрес, время работы и форма записи
- booked.html - страница после отправки формы

Сделано на Bootstrap 4, сайт выложен на GitHub Pages.
